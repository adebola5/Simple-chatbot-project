# React Chatbot Application

A beginner-level interactive chatbot application developed using React as part of my frontend development learning journey.

The project allows users to enter messages, submit them and receive chatbot responses through an interactive messaging interface. It was developed by following the chatbot project in SuperSimpleDev's React tutorial.

## Technologies Used
- React
- JavaScript (JSX)
- HTML
- CSS
- Vite
- SuperSimpleDev chatbot JavaScript library

## Features
- Interactive chatbot messaging interface.
- User message input and submission.
- Display of user and chatbot messages.
- Dynamic rendering of conversation messages.
- Chatbot response functionality.
- Scrollable conversation area.
- Automatic scrolling to the latest message.

## React Concepts Practised
- Functional components and JSX.
- Component reusability.
- Props and data sharing between components.
- React state management using `useState`.
- Event handling and controlled inputs.
- Dynamic rendering using JavaScript `map()`.
- Conditional rendering.
- Lifting state up.
- Side effects using `useEffect`.
- DOM references using `useRef`.

## Running the Project Locally
1. Clone the repository:
   git clone YOUR_GITHUB_REPOSITORY_URL
   
3. Navigate into the project directory:
   cd YOUR_PROJECT_FOLDER

4. Install the dependencies:
   npm install

5. Start the development server:
   npm run dev

6. Open the local URL displayed in the terminal.

## Prompts to be entered into the chatbot
This chatbot responds to particular supported inputs and may return a default response when it does not recognise a message. It is not a full AI system and it only responds to certain messages
1. Hello chatbot
2. How are you
3. What is the current date
4. Flip a coin
5. Roll a dice
6. Thanks
7. You can send an empty message
8. Any other messages besides the ones specified, will result in the chatbot sending a message that it does not understand your request
